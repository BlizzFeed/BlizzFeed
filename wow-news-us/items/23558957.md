# Policy Update for Input Broadcasting Software

- URL: https://worldofwarcraft.blizzard.com/en-us/news/23558957/policy-update-for-input-broadcasting-software
- Date: 2020-11-03T22:00:00Z
![](https://bnetcmsus-a.akamaihd.net/cms/blog_thumbnail/d3/D39KEEBDN3I81546879452183.jpg)

The use of input broadcasting software that mirrors keystrokes to multiple WoW game clients will soon be considered an actionable offense.
