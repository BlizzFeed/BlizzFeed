# Diablo Immortal Bug Fixes and Patch Notes for All Platforms

- URL: https://news.blizzard.com/en-gb/article/24244401/diablo-immortal-bug-fixes-and-patch-notes-for-all-platforms
![](https://bnetcmsus-a.akamaihd.net/cms/blog_thumbnail/gi/GIK2XSE1AYCK1698269352589.jpg)

> We will continually update this blog with all bug fixes and patches the team implements for Diablo Immortal on all platforms.

---

The Diablo Immortal team has been diligently monitoring your feedback and working to introduce bug fixes and patches to further improve your playing experience. As we implement these types of changes for the iOS, Android, and PC versions of Immortal, we will update this list.

Bug fixes are typically applied at a higher frequency, addressing smaller, related issues. They don’t require a large download to be applied to the game. Patches are larger client-side updates that require a download for players to obtain. New patches will require players to update before they can continue playing.

***Please check out [here](https://news.blizzard.com/article/24166781/) for the previous patch notes.***

---

## April 14, 2026—Bug Fixes

**Shop**

- Fixed an issue where some players did not receive purchased items from the Web Shop using the new Shop interface.

**Gameplay**

- Fixed an issue where Familiars could not be used in the Mad King’s Breach dungeon.

---

## March 31, 2026—Bug Fixes

**Gameplay**

- Fixed an issue where some clans were no longer appearing on Clan Leaderboards.
- Fixed an issue where the Leviathan Tomb’s Legendary Gem Drop Pool 50% drop rate event was not active on Korean servers.

---

## March 17, 2026—Bug Fixes

**Gameplay**

- Fixed an issue where Battle Pass 50 Accumulated Rewards allowed players to select the Warlock weapon for the wrong class. Affected players had the incorrect weapon removed and were granted the correct class weapon via in-game mail.

---

## February 17, 2026—Bug Fixes

**Gameplay**

- Fixed an issue where the Interact key was not functioning as intended.
- Fixed an issue with the Ballad of the Moon Phantom Market’s timing.

---

## January 27, 2026—Bug Fixes

**Gameplay**

- Fixed an issue when claiming rewards from Familiar Expeditions.

---

## January 13, 2026—Bug Fixes

**Gameplay**

- Fixed an issue with the Monk's legendary items Fate and Fortune and Gift of Suffering where one would lose 10% of their health on each primary attack when equipped at the same time.
- Fixed an uncommon issue in Battleground where players would only be matched against AI opponents instead of real players.
- Fixed an issue where players could egregiously level past the Server Paragon Level cap.
