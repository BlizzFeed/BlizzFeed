Pause from your tome of demon summoning, Adventurer. These are the Patch notes for the 3.1.1 Client Patch for the Reign of the Warlock, our known issues can be found here.

## Bug Fixes

#### General

- Fixed an issue with VFX distortion in Chronicle's backlight when applied on Amazon.
- Fixed the game client freezing.
- Fixed a crash when interacting with the available game list with mouse and keyboard.
- Fixed not being able to craft 'Mosaic' runeword online non-ladder.
- Fixed Diablo Lightning Breath to hit characters at point blank range.
  - Note: This was fixed earlier with Patch 3.1.

#### UI

- Fixed Mania runeword improperly appearing in the Chronicle as Hustle.
- Fixed tooltip for Apocalypse ability.
- Fixed title screen error from appearing.
- Fixed an issue where the Chronicle text appears as ‘eligible’ for items that have already been discovered.

#### Console

- Fixed an issue where player would get locked on 'Ladder Board' UI after docking or undocking the Nintendo Switch®.
- Fixed a crash when searching Chronicle on Nintendo Switch®.
- Fixed crash from Docking or Undocking while on Options 'Brightness' or 'Screen Space' when playing on Nintendo Switch®.
- Fixed crash when connecting the Nintendo Switch® to a Dock with the Loot Filter's 'Edit rule' tab open.
- Fixed an overlap issue with UI on handheld platforms when using mouse and keyboard.
