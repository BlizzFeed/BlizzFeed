# Overwatch Cosmetics Update Countdown

- URL: https://overwatch.blizzard.com/en-gb/news/21353116/overwatch-cosmetics-update-countdown
![](https://bnetcmsus-a.akamaihd.net/cms/blog_thumbnail/h9/H9G2SVB5OCNR1516149683144.jpg)

> Our cosmetics update is almost here! Join us as we reveal some of the new collectibles—including sprays, emotes, skins, and more—coming soon to Overwatch.

---

New year, new gear!

We're expanding our core cosmetics collection to include over 100 new items—including skins, sprays, player icons, emotes, and more—for all 26 heroes. And, starting **January 23**, you’ll be able to earn these cosmetics in standard Loot Boxes as well as unlock them via the Hero Gallery all year round.

[We've already announced a few of the items included in this update at BlizzCon 2017](https://twitter.com/playoverwatch/status/926584802282635264), but there's so much more to share! Leading up to the official release next week, we'll be unveiling new cosmetics each day for the next six days. Check out the galleries below to see what's already been revealed, and be sure to visit this page daily for a first look at some of the newest collectibles coming soon.
