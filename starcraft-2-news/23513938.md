> 2020 Ladder Season 3 is now live!

---

**Update on 30 September 2020: Ladder Season 3 is now live, and some map bugs have been fixed below.**

#### BUG FIXES

- Lightshade LE
  - Fixed an issue where the Reaper would not path properly at times near the Reaper ramps.
  - Fixed an issue where the lobby screenshots rotated incorrectly.
- Jagannatha LE
  - Fixed an issue where air and ground units could clip into various doodads.
  - Fixed an issue where units could be partially hidden inside the ground foliage.
  - Fixed an issue where certain doodads didn’t display occlusion lines.
  - Added decals near the Reaper cliffs to help highlight them.
  - Fixed an issue where units could clip into certain doodads near ramps.
- Oxide LE
  - Moved the position of the rocks near the third base to make it a bit more challenging for enemy Siege Tanks to reach and attack the base.
  - Fixed an issue where enemy players could wall off the starting ramps.
  - Fixed an issue where Overlords located on the Overlord platforms could be attacked improperly.
  - Fixed an issue where air units can clip into tree doodads.
  - Removed the tree and metal doodads positioned on the Reaper ramps.
- Romanticide LE
  - Fixed an issue where creep couldn’t spread properly in certain areas of the map.
  - Fixed an issue where enemy players could wall off the starting ramps.
  - Adjusted the location of the natural base to prevent a Photon Cannon wall in location.
- Tuonela LE
  - Fixed an issue where certain doodads weren’t displaying occlusion lines.
  - Fixed an issue where team placement locations were missing.
  - Fixed an animation pop issue with Rock Towers.
  - Fixed an issue with line of sight blockers not blocking vision properly.
- Polka LE
  - Fixed an issue where units can be dropped onto a cliff that was intended to be unpathable.
  - Fixed an issue where certain doodads weren’t displaying occlusion lines.
  - Fixed an issue where units could clip into doodads.

2020 Ladder Season 3 brings new 1v1 and Team maps to ladder!

These maps will be available for playtesting or exploration in the Custom Games section of Multiplayer today. Below are some descriptions from the creators of the maps. Please click on the images to see the detailed views.

Along with the new map pool, the new season also brings everyone a free name change! Simply follow the steps below to change your character name:

- Log in to the game
- Left click on your character portrait in the upper right corner
- Click the gear icon next to your current name
- Click Change Name
- Enter a new name
