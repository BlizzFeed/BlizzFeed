We’ve recently released a Heroes of the Storm patch in order to address a few live bugs. Read on for details.

---

### Bug Fixes

**General**

- Fixed an issue preventing healing and shielding from tracking on the out-of-game score screen and event quest trackers.
- Fixed an issue causing event progress to fail to track if the quest was chosen while a player was in queue.

**User Interface**

- Fixed an issue causing ability icons to appear slightly zoomed in.
