#### Bugfixes and Improvements

**Arclight Energy**

- Fixed an issue that would cause Arc Energy not to be granted to players with max-level collections in Player versus Player, Siege, and Raid.
- Fixed a visual bug that would cause a player's Arc Energy total not to update correctly. This issue would happen when receiving Arc Energy instead of Stars for Minis with max Star Points.
- An Arc Energy reward should now be shown instead of Stars for Minis that are max Star Points.

**War Chest**

- Fixed an issue that would cause the Guild War Chest to sometimes grant duplicate rewards.

**Rewards**

- Fixed an issue that would make Star Tomes unclaimable.
- Fixed an issue that would cause Star Tomes to sometimes not grant Stars.
- Fixed an issue that would cause the incorrect names to display when claiming rewards.
- Fixed the error popup that would sometimes display when claiming Troop rewards from Daily Rewards.
- Fixed an issue that would cause Tome rewards not to be delivered after being claimed from Daily Rewards.
- Rewards that grant Minis should now prioritize non-maxed Minis in the choices given.

**Guild**

- Fixed an issue that would cause Guild chat to always scroll to the top. Guild chat should now always display the most recent message.
- Fixed an issue that would cause the Emote menu not to display all emotes after being opened multiple times.

**Shop**

- Fixed an issue that would cause Shop offers to display +0 Stars when a player has the Mini offered at max Star Points.
