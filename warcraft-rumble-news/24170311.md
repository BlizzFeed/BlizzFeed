# We've Reworked Player Versus Player!

- URL: https://news.blizzard.com/en-gb/article/24170311/we-ve-reworked-player-versus-player
![](https://bnetcmsus-a.akamaihd.net/cms/blog_thumbnail/qp/QPZLI2BLKQYA1720496694773.png)

> We've reworked Player versus Player with different rewards, shorter matches and Honor contribution! This update also includes bug fixes for matchmaking, daily offers, Anub'arak and more.

---

#### Player Versus Player

We've reworked Player versus Player (PvP) and changed how rewards are earned, how Honor is calculated, match length, and more.

##### Victory Points

The Honor rewards will be changing to Victory Road rewards. All rewards will now be earned through accumulating Victory Points, instead of Honor.

- Victory Points are earned upon completion of a PvP match, regardless of victory or defeat. Wins and win streaks will reward additional points. Victory Points will never be taken away due to a loss.
- Victory Points will reset every season and can be earned again. Rewards may change each season.

##### Honor

Honor will continue to be tracked as it has been and will be used to place players into their Honor ranks.

- At the end of each season, there will be a rank placement and associated rank rewards.
- We've added new ranks including Top 1 and Top 100.
- These new rankings will not be able to be tracked in game. We're hoping to include this in a future update. Ranks beyond 100 can still be tracked in game with the Honor rank system.
- Honor rating has been simplified and is no longer calculated per Leader. All Leaders can contribute to Honor rating.
- There is no longer matchmaking based on which Leader is chosen.

##### Match Length

We've shortened PvP match times from 3 minutes and 30 seconds to 2 minutes. Overtime will still be 1 minute.

---

#### Bug Fixes

- Fixed issues that prevented players on PC and mobile from matching with each other for Raid, Siege, and PvP.
- Fixed an issue with opening consecutive tome rewards. Players may see multiple notifications for unclaimed tomes after updating.
- Fixed an issue where some players could not claim daily offers.
- Fixed an issue that caused the Surrender option to be available in multiplayer game modes.
- Fixed an issue that would cause Star Point Tomes to sometimes show empty options.
- Fixed an issue causing an icon to show in the bottom left of the world map when using certain resolutions.
- Anub'arak's scarabs should no longer stop spawning when multiple Anub'araks are on the map.
- Fixed an issue where Anub'arak would spawn too many scarabs in Dungeons when using the Strange Dust Relic.
