# Log in for Epic Anniversary Rewards

- URL: https://news.blizzard.com/en-gb/article/24146993/log-in-for-epic-anniversary-rewards
![](https://bnetcmsus-a.akamaihd.net/cms/blog_thumbnail/ck/CK6I3KBX6H5R1730219136455.png)

> A Core Trader has been added, Anniversary Login Rewards have been added, Collection Level has been increased and more!

---

#### Core Trader

We've permanently added a Core Trader! You can find this option below the Arclight Energy in the Shop tab.

| **Core** | **Cost** |
| --- | --- |
| Rare Core | 300 Coins |
| Epic Core | 5 Rare Cores |
| Legendary Core | 5 Epic Cores |

#### Collection Level

- Collection Level will now be uncapped.
- Most levels will continue to give 50 Coins per level (75 with Booster) and now every 5 levels at 55 and above will be Star Tomes x 2.

#### Anniversary Login Event

Celebrate *Warcraft Rumble's* one year Anniversary and collect a new reward each day. Login days do not need to be consecutive.

| **Schedule** | **Reward** |
| --- | --- |
| Day One | Grunt Profile Avatar |
| Day Two | Footmen x 2 |
| Day Three | Major XP Tome |
| Day Four | Warsong Grunts x 2 |
| Day Five | Footmen Profile Avatar |
| Day Six | Grommash Hellscream x 1 |
| Day Seven | Golden Kobold Skin |
| Day Eight | S.A.F.E. Pilot x 2 |
| Day Nine | Witch Doctor x 2 |
| Day Ten | Mega XP Tome |
| Day Eleven | Golden Kobold Avatar |
| Day Twelve | Tirion Fordring x 1 |
| Day Thirteen | Golden Tower Skins |
| Day Fourteen | Dryad x 2 |
| Day Fifteen | Quilboar x 2 |
| Day Sixteen | Star Tome |
| Day Seventeen | Whelp Eggs x 2 |
| Day Eighteen | Harpies x 2 |
| Day Ninteen | Mega Leader XP Tome |
| Day Twenty | Sylvanas x 3 |
| Day Twenty One | 500 Coins |
| Day Twenty Two - Twenty Eight | 500 Tickets\* |

\*The Tickets will be converted into Arclight Energy at the end of the event period at a 20:1 ratio.

#### Multiple Event Functionality

We've added the ability to run multiple events at the same time! More details to come on this soon.
