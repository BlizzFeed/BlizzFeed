# Hotfixes: March 28, 2024

- URL: https://news.blizzard.com/en-gb/article/24073125/hotfixes-march-28-2024
![](https://bnetcmsus-a.akamaihd.net/cms/blog_thumbnail/oe/OEY7DZW8FIE91706649024511.png)

> Fixed an issue where players were unable to claim Tomes, as well as some user interface fixes and PvP changes.

---

#### User Interface

- Fixed an issue where players were unable to claim Tomes.
- Fixed an issue that caused the displayed army level to not include bonus levels from army upgrade slots.

#### PvP

- Goblin Sappers will no longer benifit from the First Strike modifier.

#### Additional Fixes

- Fixed an issue that caused Witch Doctor's Spirit Ward VFX to be displayed above bridges.
- Additional visual and VFX fixes.
