# [Updated]Hotfixes: March 21, 2024

- URL: https://news.blizzard.com/en-gb/article/24073122/updated-hotfixes-march-21-2024
![](https://bnetcmsus-a.akamaihd.net/cms/blog_thumbnail/oe/OEY7DZW8FIE91706649024511.png)

> We addressed a few PvP bugs, fixed the First Strike modifier and put the Gadgetzan map back in rotation.

---

#### PvP

- The First Strike modifier should no longer cause Spells to deal double damage, as intended.
- We've updated the description of First Strike to reflect this change.

The Gadgetzan map is now back in rotation!

#### Bug Fixes

- Fixed a bug where Minis couldn't be deployed near captured meeting stones in matches with the Stonebind modifier.
- Fixed an issue where Whelp Eggs would not take damage from Dragon Towers after hatching in PvP.
- Fixed an issue that would cause lower-ranked Leaders to offer crests, instead of the highest ranked Leader.
- Fixed an issue causing the edit button to not function as intended on the Dungeon Leader and PvP army pop up.
