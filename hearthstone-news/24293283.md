## Experience the Untold Tales of Azeroth’s Most Wanted

![HS_36p4_ClassSetsAnnounce_InBlog_GoldenClassSetsBundle_DB_760x428_SW01.jpg](https://bnetcmsus-a.akamaihd.net/cms/content_entry_media/E7OPGDY2GXCO1785960769139.jpg)

Azeroth’s Most Wanted features a Class Set for the following classes:

- Priest
- Rogue
- Warlock
- Warrior

Each seven-card set delivers a highly synergistic package built around fresh archetypes like Reborn Priest, Stealth Rogue, Kabal Warlock, and Pirate Warrior, along with the new Follow cards. Serving as a prequel to *Escape from Violet Hold*, these Class Sets reveal the crimes, chases, and betrayals that sent four infamous outlaws to Violet Hold. ([Check out our in-depth Class Sets blog for more details!](https://hearthstone.blizzard.com/news/24293282))

Each *Azeroth’s Most Wanted* Class Set includes seven cards: 1 Legendary, 2 Epics, 2 Rares, and 2 Commons.

You can find these cards in *Escape from Violet Hold* packs, craft them with dust, or purchase them directly. Buy an individual Class Set for your favorite class, or get all four Class Sets together in a bundle that also includes two copies of the bonus Wanted Poster Epic card and the Bounty Hunter Edwin Hero Skin.

*Note: Available purchase options vary by region.*

- **Golden Azeroth’s Most Wanted Class Sets Bundle**
  - Includes all cards in Golden form, 2 bonus Signature Wanted Poster Epic cards, and the Bounty Hunter Edwin Hero Skin.
  - Available for $79.99 USD or 12,000 Gold.
- **Azeroth’s Most Wanted Class Sets Bundle**
  - Includes all four Class Sets, 2 bonus Wanted Poster Epic cards, and the Bounty Hunter Edwin Hero Skin.
  - Available for $19.99 USD or 2,500 Gold.
- **Individual Azeroth’s Most Wanted Class Set (Priest, Rogue, Warlock, or Warrior)**
  - Available for $9.99 USD or 1,200 Gold.

## Lich Lord Kel'Thuzad Rises in Darkmoon Faire Treasures

![HS_36p4_Patch_Notes_InBlog_DFT_LichLordKelThuzad_760x428_SW01.jpg](https://bnetcmsus-a.akamaihd.net/cms/content_entry_media/LJJ1OYR1KKJ11786746514053.jpg)

From September 8 – October 13, Kel'Thuzad arrives at the Darkmoon Faire with our most feature-rich Mythic Hero Skin yet! Available for both Mage and Death Knight, this Mythic Hero Skin includes two swappable appearances, The Necromancer and The Lich, that you can switch between during your turn using the "Transform" option on his Emote Wheel. Each transformation is accompanied by dramatic visual effects and a custom animation.

![HS_36p4_Patch_Notes_InBlog_KelThuzad_Transform_GIF_760x428_SW01.gif](https://bnetcmsus-a.akamaihd.net/cms/content_entry_media/YU0IH7TBUFBY1787011984100.gif)

Lich Lord Kel'Thuzad also brings The Phylactery, a unique reactive board-corner feature that gathers power as minions take damage and die. As it fills with energy, it fuels custom Hero Power presentations for both Mage and Death Knight, including unique takes on Fireblast and Ghoul Charge. (The Phylactery appears in the corner of the board and is replaced by your Pet when one is equipped.)

![HS_36p4_Patch_Notes_InBlog_KelThuzad_Necro_PhylacteryHeroPower_GIF_760x428_SW01.gif](https://bnetcmsus-a.akamaihd.net/cms/content_entry_media/CLDYNLAULX6C1787011965544.gif)

This Mythic Hero Skin also includes a custom portrait, entrance animation, victory and defeat sequences, visual effects, sound effects, board interactions, and more.

![HS_36p4_Patch_Notes_InBlog_KelThuzad_Necro_Animations_GIF_760x428_SW01.gif](https://bnetcmsus-a.akamaihd.net/cms/content_entry_media/58RSXCX1RG6P1787011971350.gif)

## Bug Fixes

### Hearthstone

- Fixed a bug where Shadow of Demise could be played when drawn by The Kingslayers.
- Fixed a bug where Deathborne cast twice by Breakout Architect summoned an incorrect number of Volatile Skeletons.
- Fixed a bug where Mystic Misdirection could cancel Baroness Vashj's attack.
- Fixed a bug where Objection! could trigger before Double Cross, preventing Double Cross from resolving correctly.
- Fixed a bug where Violet Punisher failed to properly steal and transfer keyword effects in certain situations.
- Fixed a bug where R4T-C4TCH3R could exceed the deck size limit when paired with Sonya Shadowdancer.
- Fixed a visual bug where Sherazin, Corpse Flower, Khadgar, and Vanessa VanCleef could display unintended icons during animations.
- Fixed a visual bug where Starfall displayed incorrect visual effects on the opponent's side of the board.
- Fixed a visual bug where Arch-Villain Rafaam displayed incorrect visual effects.
- Fixed a bug where Hallazeal the Ascended's Lifesteal did not work with Cast When Drawn spells.
- Fixed a bug where matches did not immediately end when a player was defeated by Tiny Pal.
- Fixed a bug where the Discover interface did not highlight hovered cards.
- Fixed a visual bug where Golden Zuramat the Obliterator was missing its animation.

### Battlegrounds

- Fixed a bug where Huntmaster could receive unintended buffs from Timewarped Jungle King.
- Fixed a bug where cards could be destroyed when purchased if another card entered your hand first.
- Fixed a bug where Inductive Gyroblade, Flighty Portrait, and Lionfish Portrait could not be obtained through Orb of the Unknown.
- Fixed a bug where multiple copies of Cho'gall Sticker did not grant multiple Triple Rewards.
- Fixed a bug where Winner's Bread failed to grant stats to Tavern minions after a winning round.
- Fixed a visual bug where Highwayman Marin displayed the incorrect hero portrait.

### Cosmetics

- Fixed a visual bug where the Qixi Turalyon Hero Skin was missing its enemy-minion-clearing victory effect.
- Fixed a visual bug where Underfel Rift's gem clasp effect did not blend correctly with other on-screen visual effects.
- Fixed a visual bug where the Priest hero became motionless while attacking when using the Maiev, Hand of Vengeance Hero Skin.
- Fixed a visual bug where the Mathias Shaw Hero Skin overlapped its frame border.
- Fixed a visual bug where Irida Sinseeker did not display visual effects when drawing cards from the Void.
- Fixed a visual bug where response emote text was difficult to read while using the Imprisoned Lana'thel Hero Skin.

### General

- Fixed a bug that could cause the game to freeze on mobile devices when multiple end-of-turn healing effects resolved simultaneously.
- Fixed a bug that could cause a crash when entering Practice Mode on mobile for the first time.
