# [Update 3/10] Character Restoration Now Available

- URL: https://worldofwarcraft.blizzard.com/en-gb/news/24057482/update-3-10-character-restoration-now-available
- Date: 2024-10-03T17:00:00Z
![](https://bnetcmsus-a.akamaihd.net/cms/blog_thumbnail/86/86QO3TX2ZYKJ1689095653189.jpg)

Players will now be able to restore characters that have been deleted. Please note that at this time there is a 60 second delay between each undelete. You will need to refresh the character screen, change realms, or log into a character between each character restored.
