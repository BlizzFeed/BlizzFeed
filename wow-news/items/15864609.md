# Release the Names! Character Name Reclamation Coming

- URL: https://worldofwarcraft.blizzard.com/en-gb/news/15864609/release-the-names-character-name-reclamation-coming
- Date: 2015-06-19T08:37:55Z
![](https://bnetcmsus-a.akamaihd.net/cms/blog_thumbnail/OVLNQD32XKQB1321646529050.jpg)

With the upcoming Warlords of Draenor patch (6.2), we will be releasing long-dormant character names back into the wild. If you want to preserve the names of any characters you have not played since December 2010, then log them into the game now!
