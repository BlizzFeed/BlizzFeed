# Diablo IV Patch Notes (3.1)

- URL: https://news.blizzard.com/en-gb/article/24287406/diablo-iv-patch-notes-3-1
![](https://bnetcmsus-a.akamaihd.net/cms/blog_thumbnail/i5/I5P3IT3NEMCT1781805666465.png)

> We will continually update this article with all patches the development team implements for Diablo IV.

---

The Diablo IV team has been monitoring your feedback. As we introduce patches to keep your experience in Sanctuary smooth, we will update the below list and denote whether the fixes are intended for PC, Xbox, PlayStation™, or all platforms.

---

[3.1.3 Build #73224 (All Platforms)—August 12, 2026](#season-of-death-awakening-updates)

### Season of Death Awakening Updates

- The Season Rank III objective Set Fire to the Beacons will now count Escalation Nightmare Dungeons with the Ruptures affix toward completion.

### Class Changes

#### Druid

- Fixed an issue where casting Petrify on the Corrupted Reaper would cause the Corrupted Reaper’s wings to deform.

#### Necromancer

- Fixed an issue where Necromancer Shadow skills would obscure the Corrupted Reaper.

#### Warlock

- Fixed an issue where Dark Prison’s Chain Aura Variant would sometimes make the Warlock appear transparent to other players.

### Gameplay Changes

#### War Plans

- Fixed an issue where the War Plans Teleport to Infernal Hordes would sometimes fail on pre-Torment difficulties.

#### Bosses & Encounters

- Party members who join an active Echo of Mephisto encounter can now use a portal to access the third stage of the fight.
- Resummoning the Corrupted Reaper boss will now clear the previous Reaper's corpse.

---

[3.1.2 Build #73020 (All Platforms)—July 28, 2026](#game-updates)

## Game Updates

### Season of Death Awakening

- The Pit's end-of-run Invulnerability bubble has been fixed to properly account for Whisper Ambush bosses and re-added to the game:
  - The bubble will spawn immediately upon completing a Pit run if no Whisper ambush is triggered.
  - If a Whisper Ambush spawns, the bubble will be suppressed until the Whisper Ambush boss is killed.

## Bug Fixes

### Season of Death Awakening

- Fixed an issue where the Whisper icon could obscure teleporting to Infernal Horde.
- Fixed an issue where killing the Soul Eater while frozen could stop monsters from spawning.
- Fixed an issue that could cause Deathtoll Chamber to complete before Soul Eater is slain.
- Fixed an issue that allowed spawning of more monsters than intended from the Altar of Avarice.
- Fixed an issue where skipping an objective could prevent progress in the Cosmic Archives Stronghold.
- Fixed an issue where Indigo mount VFX could persist after the mount is dismissed.

---

# Expansion

## Bug Fixes

### Rogue

- Fixed an issue where Rogue's Dash could deal an incorrect amount of damage when using the Shadow Play Variant.
- Fixed an issue that could allow abilities to stop Infernal Hordes from starting.

### Miscellaneous

- Updated the name of the Mythic crafting Horadric Cube recipe from "Upgrade" to "Craft".

> **Developer’s Note:** *The name is being updated so that the recipe’s functionality is consistent with the naming convention for Cube recipes.*

- Fixed an issue where Mythic Unique items could not be recycled.
- Fixed various visual texture issues.

[3.1.1 Build #72836 (All Platforms)—July 14, 2026](#bug-fixes-2)

## Bug Fixes

### Season of Death Awakening

- Fixed an issue where Nemesis Lair could fail to trigger in the Corrupted Reaper's Boss Lair.
- Fixed an issue where only one party member would receive Tower rewards.
- Fixed an issue where part of the map could fail to load in Dark Refuge dungeon.
- Fixed an issue where Tower Halo rewards could appear inverted.
- Fixed an issue where Tower Halo rewards could appear on mounts.
- Fixed an issue where Forgotten Souls were not dropping from Whisper Caches in Torment levels.

[3.1.0 Build #72592 (All Platforms)—June 30, 2026](#updates-from-ptr)

# Updates from PTR

## Game Updates

### Ruptures

- The spawn rate for elite monsters in Ruptures has been increased.
- Rupture tears will now sometimes move around the area.
- Rupture tears can now be closed quicker.
- Rupture tears now spawn more often.
- Rewards for completing Rupture and Realmwalker encounters have been generally improved.
- Ruptures now spawn less frequently in the Pit.
- The overall difficulty for Ruptures has been decreased in normal difficulty, so lower-level players can more confidently clear them.

### Unique Item Updates

- Unique, Mythic Unique, and Iconic Mythic Items can now have affixes altered via Enchanting.
- Added affixes from Enchanting, Transfiguration, and Tempering are always max rolls when added to a Mythic Unique.
- Chaotic and Focused Reroll have been removed for Unique and Mythic Unique items.
- The Upgrade to Mythic recipe in the Horadric Cube now always creates an item for the same gear slot.
- Mythic Unique Items cannot be used in the Upgrade to Mythic Unique recipe.

### New Guaranteed Unique Affixes

All Unique items now have 2 guaranteed affixes when dropped.
